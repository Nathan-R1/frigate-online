Seats

You sat down first, so the seats are yours to arrange. Freeing a seat does not remove that player from the room — they keep watching, and can take any free seat. Handing one to the computer lets a game carry on when somebody has gone; opening a computer seat back up leaves it waiting for a person.

New Game

Three ways in. Who is playing, and what they fly, comes next.

Local is one screen passed around — people and computers at the same table. Online puts the table on the server and gives you a code to hand out. Join is for when somebody has given you one.

Local game

Put at least two seats on different teams.

Seats sharing a team win and lose together. Give everyone their own team for a free-for-all — the game ends when only one team still has a Core.

Hosting puts this table on the server and gives you a code. Everyone else opens the same address, enters the code and takes a seat. Seats set to Computer are played by the computer; a seat set to Local player is held for a person, and if it empties the game waits until somebody takes it.

Join a game

Type the code the host gave you, or look for a game that still has a chair free.

OR

Room

Anyone with the code can take a free seat. A seat stays yours until you leave it — close the tab, come back tomorrow, and it is still there. Games are saved, so the server restarting does not end one.
